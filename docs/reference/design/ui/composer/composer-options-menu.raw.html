Composer Options Menu

Scope: the options (+) menu in ControlsCluster. This page is its design and acceptance list.

The options menu is the same radix dropdown as every other menu in the app — DropdownMenu / DropdownMenuContent / DropdownMenuItem from components/ui/dropdown-menu.tsx — on the shared menu tokens in components/chat/top-bar/menu-styles.ts: the glass MENU_PANEL frame (10px radius, 6px padding), itemCls rows (24px tall, 13px text, 6px radius, hover is the only tint), full-bleed MENU_SEPARATOR, and the right-aligned check column (CHECK_SLOT / CHECK_SLOT_PAD). It has no module CSS of its own.

Rows

The rows, top to bottom: Add files or photos, Record a workflow (desktop App on macOS only), a separator, Web Search, Sandbox, a separator, Unattended. Every row is PlusMenuRow (controls/menu-pieces.tsx): a DropdownMenuItem wearing itemCls(false) plus MENU_ITEM_STATES, which maps radix's keyboard highlight and disabled attributes onto the same hover rule. Layout is the shared grammar — a 16px Solar icon column, the label, optional right-side metadata, then the check column. A checked row shows a 14px ink check-circle that pops in once when it becomes checked; every other row reserves the column with CHECK_SLOT_PAD, so labels and checks sit in the same columns as the top-bar menus. Toggles (Web Search, Sandbox, Unattended) keep the menu open by preventing radix's select; Add files lets it close. An unavailable Sandbox is a disabled row that keeps its native title with the reason.

No tool switch

The menu has no Tools switch and no Access preset. Which tools a chat can call is the Agent's configuration (Agents → Capabilities → Programs: all, a selected scope or an Access preset, or none). A chat that should not call tools uses an Agent whose Programs are set to none. The composer only overlays Web Search on top of the Agent's tool set (see tool-toggle-management).

DOM and ordering

The menu renders through a radix portal on body at z-[200], above the composer's own layers; radix copies the content's z-index onto its popper wrapper and handles anchoring, flipping and collisions. It opens side="top" align="start" sideOffset={9}. No trust, privacy, concurrency or cancellation boundary is involved: this is local presentation only.

Acceptance

Production files: apps/web/components/chat/composer/controls/controls-cluster.tsx, controls/menu-pieces.tsx, components/chat/top-bar/menu-styles.ts. Regression entry: npm run check:composer-options-menu.

  • The options panel, rows, separators and checks come from menu-styles.ts; composer.module.css has no .plusMenu* rules.
  • The menu has no Tools row, no Access preset submenu and no Tools chip beside it.
  • There is no menuPosition or manually computed fixed coordinates.
