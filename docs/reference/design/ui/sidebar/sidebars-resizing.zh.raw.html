左右侧栏宽度与收起状态

左右侧栏共用同一套宽度、拖拽和收起行为。各侧栏只负责自己的导航、状态来源和主体内容。

状态约束

状态宽度规则行为
左侧展开180–480px从右边缘拖拽；超出范围时停止变化
右侧展开240–720px从左边缘拖拽；超出范围时停止变化
收起固定 63px（8px 外边距内是 47px 的卡片）左右使用同一 200ms 宽度动画
重新展开恢复收起前的合法宽度使用同一宽度动画，不丢弃刚调整的宽度

实现边界

components/layout/use-resizable-rail.ts 是唯一的宽度行为实现：保存展开宽度、限制范围、处理指针捕获、生成展开/收起样式并控制 transition。左、右侧栏分别提供范围和增长方向，不再各自维护事件监听器。手柄共用 base.css 中的 rail-resize-handle 样式，命中范围以分隔线为中心，向两侧各延伸约 8px，不改变布局宽度；外壳允许手柄溢出，内部内容容器继续裁切；仅主按钮启动拖动，并禁用手柄上的触摸平移与文字选择。

展开与收起

侧栏里的每个部件在两种状态下都存在：展开和收起都不挂载、卸载或切换 display，无论方向，也无论移动中途是否再次切换。外壳宽度在点击那一帧开始移动，.collapsed 也在同一次渲染里加上或去掉。每个部件属于以下三类之一（规则见 app/styles/base/layout.css 的 "Opening and closing"）：

类别部件运动方式
两态同一位置左栏 New chat 圆标和导航图标贴着不动的左边缘布局，从不移动；每行的底框贴着卡片移动的边缘、内缩 8px。
两态不同位置两个开关、右栏视图行、左栏底部头像开关展开时距移动边缘 8px，收起时在卡片中居中（8.5px），头部内边距按宽度的时长和曲线在两者间移动。右栏的行两态都是一列，随左侧移动边缘一起走。头像的内边距从 16px 滑到 6px。
仅展开态字标、标签、Ability 刷新按钮、收藏、会话列表、滚动分隔线、底部名字和箭头、右栏视图（Files、Activity、Resources、Detail、Context）两态都按展开宽度、贴着不动的边缘布局，由卡片裁切，从不重排；按宽度的时长和曲线淡入淡出（底部名字用自己的 160ms 曲线），只靠 opacity；从收起落定到展开落定之间 inert（不接指针、不可聚焦、退出无障碍树）。标签和底部名字在各自的行里，收起的侧栏保留这些行，所以仍可触达。

移动不改变任何部件的继承属性（pointer-events、visibility、color、自定义属性）：元素的继承属性一变，浏览器就要重算它下面整棵子树的样式，在点击那一帧就是整个会话列表（pointer-events 1,764 个元素，visibility 1,946 个，opacity 只有 1 个；实测 trace）。use-resizable-rail.ts 在落定时（宽度的 transitionend 或计时器）自己把 inert 写到最外层的仅展开态部件上，这次重算落在移动结束之后；侧栏静止收起时新挂载的部件也随之 inert。

开关的两个图形（隐藏、显示）都保持挂载并交叉淡变。data-rail-closed 标记收起已落定（宽度的 transitionend 或计时器），只有看不见的东西依赖它：窄屏下分屏时回到文档流、左栏列表的滚动复位、隐藏列表里运行标记的暂停。左栏列表滚动着收起时，导航链接随宽度滑回顶部（transform 上的一个 Web Animation），落定那一帧复位滚动。右栏视图里的工作只在展开时运行：收起时 Activity、Resources 的进程轮询、页面截图和终端读取都暂停。存储为收起的左栏在 html[data-sidebar-closed] 下首帧即为收起态，不播过渡；在挂载后的侧栏把仅展开态部件设为 inert 之前，由 interactivity: inert 让它们不可触达。

不在本次结构调整中拆分会话列表或 AppShell；它们有独立状态和交互边界，不能与侧栏外壳移动混在同一次变更中。

验收

分别将左右侧栏拖到边界后收起，应在 200ms 内平滑变为 63px，期间没有任何部件在一帧内消失或出现；再次展开应恢复各自之前的宽度。分隔线两侧约 8px 均可触发拖动，悬停和拖动时只改变鼠标光标，不增加高亮；拖动过程中离开手柄仍应继续响应，释放、取消指针或窗口失去焦点后必须恢复收起动画；窗口级结束事件补充手柄的捕获事件，移动时发现按钮已释放也结束拖动。

实现状态

已实现：左右侧栏使用同一宽度行为模块；固定导航和详情渲染分别离开外壳文件，外壳组件只负责组合。
