历史渲染与对话链接

图的 ROOT 节点只承担结构作用。它和空白的用户历史行在权威渲染之前就被排除。Chat Completions 适配器同样省略空的用户字符串和文本块，但保留只含图片的消息。已存储的历史保持不变。

复制链接使用共享的剪贴板辅助函数：依次尝试受信任的桌面 IPC、浏览器剪贴板，最后是选区兜底。原生 IPC 要求 UI 来源和所属的主框架，只接受有长度上限的字符串，并且不提供读取剪贴板的 API。只有写入成功后才显示成功；失败会明确提示。侧栏和窗格菜单使用同一个辅助函数。这修正了原生菜单回调中浏览器剪贴板激活已过期的问题。侧栏右键菜单使用现有的渲染进程弹层，所以选择操作不依赖原生弹出菜单的关闭顺序。

验收：聚焦的历史与 provider 测试、剪贴板兜底与发送方授权测试、TypeScript、文档链接、独立的规格与质量评审，以及标准的生产 App 刷新。不改动 provider 账户，不自动重放，不删除历史。
