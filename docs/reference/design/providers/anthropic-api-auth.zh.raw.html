Anthropic API 认证

OpenProgram 使用官方 Anthropic Messages API，采用 API key 并按 API 账户计费。所有使用都必须遵守适用的服务条款和使用政策。

架构

API key 登录把凭据存进凭据存储。解析器把 API key 交给 Anthropic SDK。请求使用 API key 认证。模型发现和凭据校验遵循同样的凭据要求。兼容的第三方 API 保留各自的端点和凭据。

边界

不支持的凭据类型和 provider 在发起网络访问之前即被拒绝。凭据在界面中始终打码显示。登录、模型发现和推理对支持哪些 provider 和凭据必须保持一致。

参考

Anthropic 认证与凭据要求。官方 API 使用 API key；外部 CLI 的账户管理不属于本集成。

验收

Provider、账户、登录和模型列表入口都强制使用 API key 认证。测试使用合成凭据，不发送真实的 provider 请求。验证状态记录在私有实现报告中。
