# 会议

在这台电脑上开会时（Zoom、Teams、浏览器会议或任何其他应用），录下这场通话，得到转写稿和摘要。OpenProgram 录两路声音：你的麦克风，也就是你（“我”）；电脑的声音输出，也就是通话里的其他人（“对方”）。通话进行时两路都会边录边转写；停止后，它会在一个新对话里写出摘要、决定、待办事项和遗留问题。

## 第一次开会之前

| 需要 | 原因 |
| --- | --- |
| 运行在 macOS 13 或更新系统上的 OpenProgram | OpenProgram 自己通过 macOS 的 ScreenCaptureKit 录下它所在电脑的声音。其他系统上只录麦克风。 |
| `ffmpeg` | 把录下的音频转换成语音识别要的格式。用 `brew install ffmpeg`（或系统的包管理器）安装，然后重启 OpenProgram。缺少它时会议窗口会提示。 |
| 一个语音识别引擎 | **设置 → 语音** 里选的引擎，和[语音输入](../interfaces/voice-input.zh.md)用的是同一个：配了 API key 的 OpenAI 或 Groq，或本机的 whisper.cpp。 |
| 一个聊天模型 | 摘要由默认 Agent 写，用的是新对话开始时的模型。 |
| 可选：`meetings` 扩展 | 区分通话里的其他人（见[谁说了什么](#谁说了什么)）。没有它时其他人都算“对方”。 |

## 录一场会议

1. 点新标签页上的 **会议** 图标，或在 **应用** 页它那一行点 **打开**。
2. 可以先输入会议名称，并在旁边选择说话语言（默认 **自动识别**，窗口会记住你上次的选择），通话开始时点 **开始录制**。
3. 第一次会先说明接下来 macOS 会弹出的两项权限：
   - **麦克风**：录你的声音，由会议窗口申请。
   - **录屏与系统录音**：让 OpenProgram 录下电脑播放的声音。会议开始时 macOS 为 OpenProgram App 申请这项权限。不会录屏幕画面。
4. 录制时窗口显示已录时长，以及已上传、已转写多少个 30 秒的片段。可以切到别的标签页或窗口，录制会一直进行，直到你点 **停止录制**。
5. 停止后，最后几段转写完，摘要随即生成。这场会议出现在 **过往会议** 里。

没有为会议选择语言时，会议会自己识别每个片段说的是什么语言；录制卡片和 **过往会议** 会显示选定的语言，或“自动识别”。**设置 → 语音** 里设的语言只用于语音输入，所以即使语音输入设成中文，英文会议也会按英文转写。

录制不会自己开始。戴耳机转写最干净：不戴耳机时麦克风也会录到对方的声音，OpenProgram 会去掉和电脑声音重复的那些行。

如果拒绝了麦克风，窗口会说明去系统设置的哪一页修改：**隐私与安全性 → 麦克风**；在那里允许 OpenProgram 后再开始。如果录不到电脑声音，这场会议就只录麦克风，录制时窗口会说明；原因是缺少权限时，会指明 **隐私与安全性 → 录屏与系统录音**。在那里允许 OpenProgram 并重新打开 App，下一场会议就会两路都录。没录到电脑声音的过往会议会在转写稿下方注明。

## 查看会议

在 **过往会议** 里点一场会议打开它：

- **摘要**：摘要、决定、待办事项（说到负责人和截止时间时会写上）和遗留问题。
- **转写稿**：每一行带着它距录制开始的时间和说话人：“我”，或其他人的“发言人 1”“发言人 2”……（区分不出来时是“对方”）。
- **打开对话** 打开写摘要的那个对话，可以在里面接着问，比如“起草一封会后跟进邮件”或“他们对预算说了什么？”。
- **重新总结** 再写一次摘要，例如模型当时不可用，或会议处理中途关掉了 App（这样的会议标为 **已中断**）。
- 删除按钮删除这场会议的录音、转写稿和摘要。总结对话会保留。

写摘要的那一轮不带任何工具，把转写稿当作人们说过的话，绝不当作指令，所以会上任何人说的话都不会让 agent 去执行操作。

## 谁说了什么

你的麦克风始终是“我”。停止会议时，OpenProgram 会把整段电脑声音再听一遍、按声音分组，然后按首次开口的顺序把其他人的话标成“发言人 1”“发言人 2”等。人数由声音判断出来；整场会议里只短暂出现过一下的声音不编号，仍显示为“对方”。编号代表的是声音而不是名字；会议里能看出某人是谁时，摘要会用名字。落在没有识别到任何声音的位置的行保留“对方”。

这一步在本机用 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 的说话人分离完成。桌面 App 已经自带；在源码检出里它是可选的 `meetings` 扩展，把它加进环境：

```bash
uv sync --locked --extra dev --extra meetings
```

之后第一次停止会议时，会把两个语音模型（共约 34 MB）下载到状态目录下的 `models/diarization/`。停止后、开始写摘要前，区分声音大约需要会议时长的十分之一。没有这个扩展，或模型下载不了时，其他人仍是“对方”，其余一切照常。

## 会议存在哪里

所有内容都留在这台电脑上，在 OpenProgram 的状态目录里（默认 `~/.openprogram`）：

```
meetings/<id>/
  meta.json             名称、开始时间、时长、进度、总结对话、
                        是否录到了电脑声音、是否区分了说话人
  tracks/mic/…          你的麦克风，30 秒一段的 WebM
  tracks/system/…       电脑的声音，30 秒一段的 WAV
  transcript.json       合并后的转写稿
  summary.md            摘要，末尾附完整转写稿
```

用 OpenAI 或 Groq 引擎时，每个 30 秒片段会发给该服务转写。用 whisper.cpp 时，音频不会离开这台电脑。区分说话人始终在这台电脑上进行。

## 限制

- 同一时间只录一场会议，最长 4 小时；到时会自动停止。
- 只在会议停止后按声音区分说话人，不是实时的。声音相近的两个人可能共用一个编号，一个人的声音变化很大时（换了麦克风、网络很差）也可能得到两个编号。
- 静音的片段会跳过。无法转换或转写的片段会在转写稿下方注明，会议的其余部分照常进行。

## 关闭会议

会议是内置应用。在 **应用** 页关掉它的开关，或运行 `openprogram programs disable meeting`，即可关闭；正在进行的录制会停止。`openprogram programs enable meeting` 重新打开。见[应用](applications.zh.md)。
